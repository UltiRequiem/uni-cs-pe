# Teoría del Curso: Programación Orientada a Objetos

## Conceptos Avanzados

### 1. Principios SOLID
- **S**ingle Responsibility: Una clase debe tener una única razón para cambiar.
- **O**pen/Closed: Abierto a extensión, cerrado a modificación.
- **L**iskov Substitution: Las subclases deben ser sustituibles por sus clases base.
- **I**nterface Segregation: Muchas interfaces específicas son mejores que una general.
- **D**ependency Inversion: Depender de abstracciones, no de concreciones.

### 2. Patrones de Diseño
Soluciones probadas a problemas comunes.
- **Singleton**: Garantiza una única instancia.
- **Factory**: Crea objetos sin especificar la clase exacta.
- **Observer**: Notifica cambios a múltiples objetos dependientes.
- **Strategy**: Define una familia de algoritmos intercambiables.

### 3. Relaciones entre Clases
- **Asociación**: "Usa un".
- **Agregación**: "Tiene un" (relación débil).
- **Composición**: "Es parte de" (relación fuerte, ciclo de vida compartido).
- **Herencia**: "Es un".
