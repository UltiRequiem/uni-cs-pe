# Programación Orientada a Objetos (CC211)

## Descripción
Curso de tercer ciclo dedicado enteramente al paradigma de Programación Orientada a Objetos (POO), patrones de diseño y buenas prácticas de desarrollo de software.

## Lo que deberías haber aprendido
- Principios SOLID.
- Patrones de Diseño (Creacionales, Estructurales, de Comportamiento).
- Herencia, Polimorfismo, Abstracción y Encapsulamiento a profundidad.
- Manejo de excepciones y errores.
- Pruebas unitarias (Unit Testing).

## Lo que deberías ser capaz de hacer
- Diseñar arquitecturas de software robustas y escalables.
- Implementar patrones de diseño adecuados para problemas específicos.
- Escribir código limpio, mantenible y testeable.

## Recursos Recomendados
- [Refactoring.Guru](https://refactoring.guru/design-patterns) - La mejor guía visual para patrones de diseño.
- [Design Patterns: Elements of Reusable Object-Oriented Software](https://en.wikipedia.org/wiki/Design_Patterns) - El libro clásico "Gang of Four".
- [Clean Code](https://www.amazon.com/Clean-Code-Handbook-Software-Craftsmanship/dp/0132350882) - Lectura obligatoria para calidad de código.
