# Arquitectura de Computadores (CC221)

## Descripción

Curso de cuarto ciclo enfocado en la comprensión del hardware de las
computadoras, desde compuertas lógicas hasta la programación en bajo nivel
(Ensamblador) y microcontroladores.

## Lo que deberías haber aprendido

- Arquitectura de Von Neumann y Harvard.
- Ciclo de instrucción (Fetch, Decode, Execute).
- Programación en lenguaje Ensamblador (MIPS, 8051).
- Manejo de interrupciones y temporizadores.
- Interfaces de entrada/salida (GPIO, UART).
- Diseño de circuitos digitales básicos.

## Lo que deberías ser capaz de hacer

- Escribir y depurar programas en Ensamblador.
- Programar microcontroladores (como el 8051) para tareas específicas.
- Entender cómo el software interactúa con el hardware.
- Analizar el rendimiento de diferentes arquitecturas.

## Recursos Recomendados

- [Computer Organization and Design (Patterson & Hennessy)](https://www.amazon.com/Computer-Organization-Design-MIPS-Architecture/dp/0124077269) -
  La "biblia" de la arquitectura de computadores.
- [MARS MIPS Simulator](http://courses.missouristate.edu/KenVollmar/mars/) -
  Simulador para MIPS.
- [EdSim51](https://www.edsim51.com/) - Simulador para el microcontrolador 8051.
- [Nand2Tetris](https://www.nand2tetris.org/) - Curso increíble para construir
  una computadora desde cero.
