# Fundamentos de Programación (CC112)

## Descripción
Curso de segundo ciclo enfocado en profundizar los conocimientos de programación en C++, introduciendo estructuras de datos más complejas y principios de diseño.

## Lo que deberías haber aprendido
- Manejo avanzado de punteros y referencias.
- Asignación dinámica de memoria (`new`, `delete`).
- Estructuras de datos básicas (pilas, colas, listas enlazadas).
- Introducción a la Programación Orientada a Objetos (Clases, Objetos).
- Manejo de archivos (lectura y escritura).

## Lo que deberías ser capaz de hacer
- Diseñar e implementar sistemas pequeños (como una Biblioteca Virtual).
- Gestionar memoria manualmente sin fugas (memory leaks).
- Manipular archivos de texto y binarios para persistencia de datos.

## Recursos Recomendados
- [C++ Data Structures](https://www.geeksforgeeks.org/data-structures/) - Estructuras de datos en C++.
- [Object-Oriented Programming in C++](https://www.tutorialspoint.com/cplusplus/cpp_object_oriented.htm) - Conceptos de POO.
- [Projecto de Referencia](https://github.com/UltiRequiem/biblioteca-virtual) - Ejemplo de proyecto final.
