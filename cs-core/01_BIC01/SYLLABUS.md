# Syllabus: Introducción a la Computación (BIC01)

## General Information

- **Course Code**: BIC01
- **Prerequisites**: None
- **Credits**: 4
- **Hours**: 2 Theory, 4 Practice

## Course Description

Introduction to the fundamental concepts of computer science, including
algorithms, data structures, and programming languages. The course covers the
history of computing, number systems, and the basics of operating systems and
networks.

## Learning Units

### 1. Introduction to Computer Science

- History of computing.
- The computer as a system.
- Hardware and Software.

### 2. Number Systems and Data Representation

- Binary, Octal, Hexadecimal systems.
- Data representation (Integers, Floating point, Characters).

### 3. Algorithms and Problem Solving

- Definition of algorithms.
- Flowcharts and Pseudocode.
- Structured programming concepts.

### 4. Computer Architecture Basics

- CPU, Memory, I/O.
- Von Neumann Architecture.

### 5. Operating Systems Fundamentals

- Definition and History.
- Process management, Memory management.

### 6. Computer Networks

- Basic concepts.
- Internet and World Wide Web.

### 7. Programming Languages

- History and Paradigms.
- Compilers and Interpreters.

## Evaluation

- **Midterm Exam (EP)**
- **Final Exam (EF)**
- **Average**: (EP + EF) / 2
