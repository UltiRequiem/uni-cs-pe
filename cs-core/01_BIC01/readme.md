# Introducción a la Computación (BIC01)

## Descripción
Este es el primer curso de la carrera, enfocado en los fundamentos de la programación utilizando C++.

## Lo que deberías haber aprendido
- Fundamentos de la programación estructurada.
- Sintaxis básica de C++ (variables, tipos de datos, operadores).
- Estructuras de control (if, else, switch, loops).
- Funciones y modularización.
- Arreglos y cadenas.
- Introducción a punteros y gestión de memoria.

## Lo que deberías ser capaz de hacer
- Escribir programas básicos en C++ para resolver problemas matemáticos y lógicos.
- Entender y depurar código simple.
- Implementar algoritmos básicos de ordenamiento y búsqueda.

## Recursos Recomendados
- [Learn C++](https://www.learncpp.com/) - Guía completa y gratuita.
- [C++ Reference](https://en.cppreference.com/w/) - Documentación técnica.
- [CS50's Introduction to Computer Science](https://www.edx.org/course/introduction-computer-science-harvardx-cs50x) - Excelente introducción general.
