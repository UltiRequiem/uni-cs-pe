# Matemática Discreta

## Descripción

Curso fundamental para CS que cubre lógica, combinatoria, grafos y teoría de
números. Provee las herramientas para analizar algoritmos.

## Lo que deberías haber aprendido

- Construir demostraciones matemáticas rigurosas.
- Contar estructuras complejas.
- Modelar problemas usando grafos.
- Entender la aritmética modular (base de la criptografía).

## Lo que deberías ser capaz de hacer

- Probar la corrección de algoritmos usando inducción.
- Calcular la complejidad de algoritmos básicos.
- Resolver problemas de recurrencia.
