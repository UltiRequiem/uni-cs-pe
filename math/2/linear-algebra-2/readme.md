# Álgebra Lineal II

## Descripción

Continuación del estudio de estructuras algebraicas lineales, con énfasis en
descomposiciones matriciales avanzadas y teoría espectral.

## Lo que deberías haber aprendido

- Calcular la forma de Jordan de una matriz.
- Entender la dualidad en espacios vectoriales.
- Clasificar formas cuadráticas.

## Lo que deberías ser capaz de hacer

- Aplicar SVD para reducción de dimensionalidad (PCA).
- Analizar la estabilidad de sistemas dinámicos lineales.
