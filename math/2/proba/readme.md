# Probabilidades

## Descripción

Curso que establece las bases matemáticas para modelar la incertidumbre.
Esencial para Ciencia de Datos e Inteligencia Artificial.

## Lo que deberías haber aprendido

- Calcular probabilidades de eventos complejos.
- Identificar y usar distribuciones de probabilidad adecuadas.
- Entender el significado de la esperanza matemática y la varianza.

## Lo que deberías ser capaz de hacer

- Resolver problemas de probabilidad condicional usando Bayes.
- Modelar fenómenos aleatorios simples.
- Aplicar el Teorema del Límite Central para aproximaciones.
